# Vi 进阶命令 — spec #8e

在 #8b（Vi 核心）基础上扩展常用命令，全部加进纯逻辑 `ViEngine`（GUILESS 可单测，无新依赖、
无 QML 改动——`Vi.handleKey` 已转发任意键）。

## 新增命令

| 类别 | 命令 |
| --- | --- |
| 词尾动作 | `e`（到当前/下个词尾，支持计数 `Ne`） |
| 行内查找 | `f<c>`（行内右找 c）、`F<c>`（左找）、`t<c>`（停 c 前一格）、`T<c>`（停 c 后一格） |
| 重复查找 | `;`（重复上次 f/F/t/T）、`,`（反向重复） |
| 替换 | `r<c>`（替换光标处字符；`Nr<c>` 替换 N 个） |
| 大小写 | `~`（翻转光标处大小写并右移；`N~` 翻转 N 个） |
| 行缩进 | `>>`（行首插 `\t`）、`<<`（删行首 `\t` 或最多 2 空格）；`N>>`/`N<<` 覆盖 N 行 |

## 待参（pending-argument）机制

`f/F/t/T/r` 按下后置 `m_pendingChar`，**下一个键作为参数**（目标字符 / 替换字符）消费——
该消费在计数累加之前，故 `f5`、`r5` 的 `5` 被当作字符而非计数。`Esc` 经 `reset()` 清待参。
`;`/`,` 用记录的 `m_lastFindCmd`/`m_lastFindTarget` 重复（`,` 反向 f↔F、t↔T）。

`>>`/`<<` 复用操作符挂起（`m_pendingOp`）：第一个 `>` 置挂起、第二个触发；按行收集起点，
edits 多条非重叠（应用方按 start 降序应用，偏移有效）。

## 验证

- **单元测试** `tests/test_viengine.cpp`（扩展，GUILESS）：
  - `e`：`"foo bar"` → 2 → 6；`2e` → 6；
  - `f/F/t/T` + `;`/`,`：`"a.b.c"` `f.`→1、`;`→3、`,`→1、`t.`→0；
  - `r`：`"abc"` `rX`→`"Xbc"`(cursor0)、`2rY`→`"YYc"`(cursor1)；
  - `~`：`"abc"` `~`→`"Abc"`(cursor1)、`3~`→`"ABC"`(cursor3)；
  - `>>`/`<<`：`"a\nb"` `>>`→`"\ta\nb"`、`<<`→`"a\nb"`、`2>>`→`"\ta\n\tb"`。
  - **ctest 22/22 全绿**（test_viengine 11 组：#8b 6 + #8e 5）。
- 构建通过；MarkdownEditor.qml 未改（qmllint 仍干净）；offscreen 启动无错。

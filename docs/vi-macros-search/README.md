# Vi 宏 q / @ — spec #8h

为纯逻辑 `ViEngine`（#8b…#8g）实现 Vi 宏：`q<reg>` 录制按键序列、`@<reg>` 回放。全在引擎内
（GUILESS 可单测，无新依赖、无 QML 改动）。

## 机制

- **录制**：`q<reg>`（reg 为字母）开始把后续按键录入寄存器，**边录边正常执行**；再按 `q` 停止。
  - `q`/`@`/寄存器名等控制键在 handleKey 顶部被拦截 return，**不录入**序列。
  - 录制 `append` 在 dispatch 之前，故录到的是会执行的命令键。
- **回放**：`@<reg>` 在当前光标处依序回放该寄存器按键。
  - 回放在**本地文本副本**上推进（每步 edits 降序应用、光标/选区更新），支持**多步编辑**。
  - 最终以**一条整篇编辑** `{0, origLen, finalText}` 返回——调用方 `remove(0,len)+insert(0,finalText)`。
  - `m_replaying` 防重入（回放期不录制、`.`/`@` 不递归）。
- `reset()`（Esc）清 `pendingQ`/`pendingAt`，**保留**录制状态与 `m_macros`（宏跨命令存活）。

## 已覆盖 vs 边界

- ✅ 录制/回放 Normal 模式结构性命令宏：`x`/`dd`/`0`/`j`/`dw`/`p` 等（含计数）。
- ⛔ 宏内进入 Insert 后键入的文本暂不被引擎录入（同 `.` 的 Insert 边界，#8g）。
- 📝 `/`/`?` 搜索 + `n`/`N`、可视块 `Ctrl-V` **超出纯引擎边界**（需与编辑器查找框/块状选区 UI 集成）——
  按需在编辑器层接入，**不另派生 spec**。

  - 多命令宏 `qa` `0xj` `q`（`"x1\nx2\nx3"` → `"1\nx2\nx3"`），`@a` → `"1\n2\nx3"`，`@a` → `"1\n2\n3"`；
  - 空寄存器 `@z` → 不变。
